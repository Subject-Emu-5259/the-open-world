# THE OPEN WORLD — v0.99.2 Release Notes
*Released August 25, 2026*

## Summary
This patch rebuilds the save flow and NPC conversation system so players stop losing progress on refresh and NPCs actually greet and respond instead of feeling like bots.

## What Changed

### Save System — Server-First Persistence
- `GET /api/init` now reads the player directly from Redis slot 1 and returns `{ hasPlayer: true, player }` when a save exists.
- Every successful command auto-saves the updated player to slot 1 via `/api/save` (fire-and-forget).
- The client flushes the current player to the server on `visibilitychange` and `beforeunload` so tab close/reload does not wipe progress.
- `localStorage` is kept only as an offline fallback, not the source of truth.
- The splash screen auto-detects a server save and surfaces a **Continue** button; **New Game** only overwrites when explicitly chosen.
- Removed the dead duplicate `src/server/server.ts` so save logic has a single source of truth.

### NPC Conversation Overhaul
- `talk [name]` and `greet [name]` now trigger a real contextual greeting generated by the conversation engine.
- NPCs reference relationship, mood, time of day, district, and role in their opening line.
- Conversations can be exited with `bye`, `goodbye`, `exit`, `leave`, `later`, `im out`, `ima head out`, or `end`.
- `text [name] [message]` now reads relationships correctly and gives relationship-aware replies.
- `people` now falls back to showing all city NPCs when district data is missing, so no one feels invisible.

### Cohesion & Polish
- `GameEngine.startGame(forceNew)` clears state on a new game and returns a fresh player.
- `GameEngine.handleResponse` always returns the updated `player` object so the client stays in sync.
- The splash screen now lets players choose **Continue** or **New Game** instead of silently starting over.

## How to Play After Update
1. Open the game in Reddit.
2. If you had an existing save, click **Continue**.
3. Play normally; progress auto-saves after every action.
4. To restart, choose **New Game** from the splash or run `restart` in-game.
